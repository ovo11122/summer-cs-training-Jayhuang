# Week01 Text Statistics Program

## 功能 

该程序可以对输入的文本进行提取单词，统计文本的行数，总单词数，与数量最多的10个单词
用户可查询里面单词出现的次数

## 操作方法

用户打开终端以 'cd 文本存放文件夹地址' 为格式输入打开文件夹   
再以 'python .\week1_program.py .\文本文件名称 -o .\结果存放文件名称' 为格式运行文件
（可不输入-o与结果存放文件，结果会自动存放在当前文件夹中并名为result.txt）
再跟随提示进行操作以查询单词出现次数即可
（上文''为隔开方便阅读，并非格式内容，将中文部分替换成具体文件地址即可）

## 结果存放

运行结束后在提供的文件夹中会有提供的文件名的文本文档
里面会有提供文本所统计的行数，单词数，数量最多的10个单词以及查询单词的出现次数
