# Week02 学生成绩数据处理与排序算法比较
## 项目简介

本项目使用对学生成绩CSV数据进行读取、清洗、统计、排序。
项目完成数据处理,使用集合和字典完成去重、分类和索引查找，并自行实现冒泡排序、选择排序、插入排序和归并排序。

## 主要功能
- 检查字段类型、缺失值和重复记录
- 使用集合按照学号进行数据去重
- 使用字典统计各班人数并按班级分类学生
- 检查不在0～100范围内的异常成绩
- 使用对应科目的平均分填补缺失值
- 计算每名学生的平均分
- 筛选平均分不低于85分的学生
- 按照班级分组并汇总各科平均成绩
- 比较逐行查找与字典索引查找的速度
- 自行实现四种排序算法
- 按照平均分对学生记录进行升序和降序排列
- 使用重复分数测试排序正确性
- 比较不同数据规模下各排序算法的运行时间
- 绘制并保存统计图
- 将处理结果保存为新的CSV文件
