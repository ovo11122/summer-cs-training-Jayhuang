# 第五周学习总结

## 结果
一.隐藏层不同
隐藏层大小     最佳检验损失    accuracy    precision    recall     f1    
   16             0.0349        0.9535      0.9630      0.9630   0.9630
    8             0.0447        0.9535      0.9630      0.9630   0.9630
二.学习率不同
学习率大小     最佳检验损失    accuracy    precision    recall     f1
   0.01           0.0479        0.9535      0.9630      0.9630   0.9630
  0.001           0.0451        0.9535      0.9630      0.9630   0.9630
三.批大小不同
批大小     最佳检验损失    accuracy    precision    recall     f1
   32         0.0349        0.9535      0.9630      0.9630   0.9630
   16         0.0362        0.9651      0.9636      0.9815   0.9725

由这三个对比发现隐藏层大小，学习率和批大小的改变都会对最佳检验损失改变
但是只有批大小大的改变才对其余的数据产生了改变（这里有疑问？？）
^^更正，在多次运行后发现其余值也是改变的

我在实验过程中思考每次模型的学习数据都是先从一个随机权重和偏置开始的，在经过随机的数据学习
后应该最佳检验损失也是不同的，在经过5次相同数据的运行后发现确实是这样
分别为：0.0348  0.0316  0.256

## 遇到的问题（已解决）
对学习率取0.001不理解 最佳学习率怎么得到
根本没有啥“智能”，都只是大数据对模型的训练而已
怎么把tensor换成list
append和extend有啥区别：append整个加入 extend挨个加入
该怎么显示线条名称
为什么验证指标不变
